# Рекомендательная система для интернет-магазина (ALS)

Дипломный проект.  
Разработка рекомендательной системы, которая выдаёт топ-3 товара для каждого пользователя с целью увеличения допродаж.

## Бизнес-задача

Увеличить оборот от рекомендаций на главной странице интернет-магазина на **20%**.

**Ограничение:** на главной странице только 3 слота под рекомендации.

## Техническая задача

Для каждого пользователя сформировать топ-3 товара с максимальной вероятностью покупки.

**Основная метрика:** Recall@3

## Данные

- История событий пользователей (`view`, `addtocart`, `transaction`)
- Иерархия категорий товаров
- Свойства товаров (более 70 признаков)

Период данных: июнь 2015 года.

## Подход и модель

Использована **коллаборативная фильтрация** на основе матричной факторизации:

- Модель: **ALS** (Alternating Least Squares)
- Библиотека: `implicit`
- Параметры:
  - `factors = 100`
  - `regularization = 0.5`
  - `iterations = 30`

Модель обучалась только на истории покупок (транзакций) для получения чистого коллаборативного сигнала.

## Результаты

| Модель                    | Recall@3 |
|--------------------------|----------|
| Топ-популярные (baseline)| 4.2%     |
| **ALS (наша модель)**    | **12.5%**|

Улучшение относительно baseline — **в 3 раза**.
